## Viewing the HTML prototype (important)

On GitHub, opening a file such as `AI-accounting/prototype.html` in the **Code** tab shows the **HTML source** in the browser. That is normal: GitHub is a code viewer, not a static host for arbitrary HTML execution from the blob UI.

**Live prototype (GitHub Pages):** [Open this prototype in the browser](https://rayliu66.github.io/Product_Design_Protfolio/AI-accounting/prototype.html)

Opening `prototype.html` from the repo **Code** tab still shows **source** only—that is expected. **Local:** clone the repo and open `AI-accounting/prototype.html`, or run `python3 -m http.server` from the repo root and visit `http://localhost:8000/AI-accounting/prototype.html`.

More detail is in [`AI-accounting/README.md`](AI-accounting/README.md).
